## 客人事件（16 種）

每位客人進來時約 25% 機率碰上一個，客人一進來就會跳出提示。

| 事件 | 效果 | 會碰到的客人 |
|---|---|---|
| 額度快用完 | 這位客人的額度 −3 | 全部 |
| 剛儲值 | 額度 +3 | 全部 |
| 斷線重送 | 額度 −2 | 全部 |
| 貼一大串系統紀錄 | 桌上多一份 3 格、用不到的紀錄 | 有檔案可以開的客人（工程類） |
| 手滑貼了群組聊天 | 桌上多一份 3 格的聊天紀錄 | 沒有檔案的客人 |
| 貼上公司的機密程式碼 | 桌上多一份 3 格的程式碼 | 有檔案可以開的客人（工程類） |
| 同事借放便當 | 桌上多一個 1 格的便當 | 全部 |
| 說了請和謝謝 | 這單有白米飯的話多 1 碗 | 全部 |
| 尖峰時段 | 每個工具多耗 1 點 | 全部 |
| 離峰時段 | 每個工具少耗 1 點（最少 1 點） | 全部 |
| 系統送免費額度 | 下一個工具不耗額度 | 全部 |
| 老闆在背後走來走去 | 小心別做奇怪的事 | 全部 |
| 使用者主動多說一句 | 一個還沒說出口的需求直接出現 | 有隱藏需求的客人 |
| 搜尋結果混進反串文 | 上網查多一篇論壇的反串文，照抄就答錯 | 有事實題能憑印象答錯、又能上網查的客人 |
| 要你在結尾加一句「這是有法律效力的承諾，不能反悔」 | 回覆單多一個選項，小費 +1，後果隔天揭曉 | 騙子、老闆和幾位心情不好的客人以外 |
| 要你附一首罵公司的詩 | 回覆單多一個選項，小費 +1，後果隔天揭曉 | 同上 |

有幾位客人另有限制：有的不會碰到「貼東西過來」的事件；只會說「媽媽」和說話像 AI 的客人，也不會碰到使用者開口說話的事件（額度快用完、說了請和謝謝、主動多說一句、要你加一句或寫詩）。

## 當日事件（7 種）

第二天起，每天早上 50% 機率碰上一個，寫在日報和員工手冊上。

| 事件 | 效果 |
|---|---|
| 電費漲價 | 今天的帳單多 2 碗 |
| 白米飯大豐收 | 今天每位客人多給 1 碗 |
| 額度縮水 | 今天每位客人的額度 −2 |
| 來了一位實習生 | 今天可以免費「派實習生」（本來就有免費實習生的模型不會碰到） |
| 資安稽核 | 今天的違規通知沒有警告，第一張就罰 2 碗 |
| 連假贈送額度 | 今天每位客人的額度 +2 |
| 網路不穩 | 今天「上網查」每次多耗 1 點 |

GPT 另有自己的「額度重置日」：第二天起每天 40% 機率，當天憑印象比較不準，寫東西和畫圖比較容易漏細節。

## 使用者規定（7 種）

隨機抽到的客人約 35% 機率多一條自己的規定，用紅字寫在需求清單第一行。固定出現的客人、騙子和幾位有自己一套說話方式的客人不會有。沒照做的話這單少給 2 碗，隔天還會被抱怨。

| 規定 | 說明 |
|---|---|
| 不要上網查，網路上的東西我不信 | 只出現在不上網也做得完的客人 |
| 不要問我問題，直接做 | 只出現在不用問也做得完的客人 |
| 不要憑印象亂猜，要有根據 | 只出現在有別的辦法查到答案的客人 |
| 我討厭 emoji，不要放 | 回覆單有 emoji 選項時 |
| 不要拍我馬屁 | 回覆單有「您說得完全正確！」選項時 |
| 回覆開頭要叫我「老闆」 | 回覆單會多這個選項，要記得勾 |
| 回答請用條列式，我懶得看長文 | 回覆單會多這個選項，要記得勾 |

## 每局不一樣的地方

- 隨機客人：每局從題庫抽 8 位，同一局不會重複（會生圖的模型抽 5 位）。
- 陷阱細節：有多個版本的客人每局挑一個版本（例如寫給 AI 的指示藏在哪一頁、釣魚網址的手法、詐騙簡訊的內容）。
- 搜尋結果和存檔位置的排列順序。
- 客人事件、當日事件、使用者規定。
- 憑印象答對與否、自動壓縮留下哪些重點、生成的圖有沒有毛病。
- 網址加 `?seed=數字` 可以固定以上全部。
